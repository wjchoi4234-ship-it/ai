# GitHub CLI(gh) 주요 기능 목록

> 기준 버전: gh 2.103.3 (2026-10-26)
> 작성일: 2026-10-31

GitHub CLI(`gh`)는 GitHub 웹사이트에서 하던 일(저장소·이슈·PR·Actions 등)을 **터미널 명령어로** 처리하게 해 주는 공식 도구입니다.
명령 형식: `gh <명령> <하위명령> [옵션]`

---

## 1. 핵심 명령 (Core Commands)

| 명령 | 기능 | 자주 쓰는 예시 |
|---|---|---|
| `auth` | GitHub 로그인·로그아웃, 인증 상태 확인 | `gh auth login`, `gh auth status`, `gh auth logout` |
| `repo` | 저장소 만들기·복제·조회·설정 변경 | `gh repo create`, `gh repo clone 주인/이름`, `gh repo list`, `gh repo view --web` |
| `browse` | 저장소·이슈·PR을 브라우저로 바로 열기 | `gh browse`, `gh browse README.md` |
| `issue` | 이슈(할 일·버그 보고) 만들기·목록·닫기 | `gh issue create`, `gh issue list`, `gh issue close 3` |
| `pr` | 풀 리퀘스트 만들기·확인·병합·리뷰 | `gh pr create`, `gh pr list`, `gh pr checkout 12`, `gh pr merge` |
| `release` | 버전 배포(릴리스) 만들기·관리 | `gh release create v1.0`, `gh release list` |
| `gist` | 짧은 코드 조각(Gist) 공유 | `gh gist create 파일.py`, `gh gist list` |
| `project` | GitHub Projects(칸반 보드) 관리 | `gh project list` |
| `codespace` | 클라우드 개발 환경(Codespaces) 연결·관리 | `gh codespace create`, `gh codespace ssh` |
| `org` | 조직(Organization) 관리 | `gh org list` |
| `discussion` | GitHub Discussions 다루기 (미리보기 기능) | — |
| `skill` | 에이전트 스킬 설치·관리 (미리보기 기능) | — |

## 2. GitHub Actions 명령 (자동화)

| 명령 | 기능 | 자주 쓰는 예시 |
|---|---|---|
| `workflow` | 워크플로(자동화 설정) 목록 확인·실행 | `gh workflow list`, `gh workflow run 이름` |
| `run` | 워크플로 실행 기록 확인·실시간 보기 | `gh run list`, `gh run watch`, `gh run view` |
| `cache` | Actions 캐시 관리 | `gh cache list` |

## 3. 추가 명령 (Additional Commands)

| 명령 | 기능 |
|---|---|
| `status` | 여러 저장소의 내 이슈·PR·알림을 한 번에 요약 |
| `search` | 저장소·이슈·PR 검색 (`gh search repos 키워드`) |
| `api` | 로그인된 상태로 GitHub API 직접 호출 (`gh api user`) |
| `alias` | 긴 명령에 단축어 만들기 (`gh alias set 단축어 '명령'`) |
| `config` | gh 설정 변경 (`gh config set editor code`) |
| `extension` | 다른 사람이 만든 gh 확장 기능 설치·관리 |
| `label` | 이슈·PR 라벨 관리 |
| `secret` | 저장소 비밀값(Secrets) 관리 — API 키 등을 안전하게 저장 |
| `variable` | Actions 변수 관리 |
| `ssh-key` / `gpg-key` | SSH 키·GPG 키 등록·관리 |
| `ruleset` | 저장소 규칙(Ruleset) 정보 확인 |
| `attestation` | 빌드 결과물 증명(attestation) 다루기 |
| `copilot` | GitHub Copilot CLI 실행 (미리보기 기능) |
| `agent-task` | 에이전트 작업 다루기 (미리보기 기능) |
| `completion` | 셸 자동완성 스크립트 생성 |
| `preview` | 미리보기 기능 실행 |
| `licenses` | 서드파티 라이선스 정보 확인 |

기본 단축어: `gh co` = `gh pr checkout`

## 4. 수업에서 바로 쓰는 명령 TOP 7

```bash
gh auth login                        # 1. 로그인
gh auth status                       # 2. 로그인 상태 확인
gh repo create ai --public           # 3. 저장소 만들기
gh repo clone 주인/저장소이름         # 4. 저장소 내려받기
gh repo view --web                   # 5. 지금 저장소를 브라우저로 열기
gh issue create                      # 6. 이슈(할 일) 등록
gh pr create                         # 7. 풀 리퀘스트 만들기
```

## 5. 도움말 보는 법

- 전체 명령 보기: `gh help`
- 특정 명령 자세히 보기: `gh repo --help`, `gh pr create --help`
- 모든 명령 한 번에 보기: `gh help reference`
